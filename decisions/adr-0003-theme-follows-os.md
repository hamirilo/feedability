# ADR-0003: 外観の既定を OS に合わせる

**状態**：採用
**日付**：2026-10-17

## 状況

desktop-platform の UI Standard §1 は「ダークを既定にする」「ライトテーマは作らない。必要になったらトークンの差し替えで足す」としている。Feedability は長い文章を読むためのアプリで、明るい場所や OS をライトにしている人にはダークだけでは読みにくい、という要望があった。

## 決定

ライトを足し、設定で「OS に合わせる / ライト / ダーク」を選べるようにする。**既定は OS に合わせる**。

## 理由

- 選択肢を足すだけなら Standard の範囲内（トークンの差し替えで足す）。逸脱は「既定」だけ。
- 読むアプリでは、OS の外観に揃っているほうが目の負担が少ない。ダークを既定にすると、ライトの OS の人は毎回設定を変えることになる。
- 既定をダークのままにする案も検討し、利用者の判断で OS に合わせるほうを選んだ。

## 影響

- `tauri.conf.json` のウィンドウから `theme: "Dark"` と `backgroundColor` を外し、Rust でウィンドウを作って保存した外観を当てる（docs/THEME.md）。起動時に一瞬違う色が出ないよう、背景色も外観に合わせる
- 新しい色を足すときは、ライトとダークの両方に値を入れる
- ほかのツールへの影響は無い（このツールだけの既定）

## 見直す条件

- 2 つ目のツールもライトを足し、既定を OS に合わせたくなったら、UI Standard §1 を直す PR を desktop-platform に出す。
