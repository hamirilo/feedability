# ADR-0005: ブラウザ拡張の受付を 127.0.0.1:41630 で待ち受ける

**状態**：採用
**日付**：2026-10-18

## 状況

ロードマップのフェーズ 7（[docs/EXTENSION.md](../docs/EXTENSION.md)）：見ているページのフィードをブラウザからワンクリックで購読し、フィードに無いページを「あとで読む」に入れたい。
ブラウザ拡張からアプリへ渡すには、アプリが 127.0.0.1 で待ち受ける必要がある。今の Feedability は待ち受けない（project-context の「該当しない Standard」に Optional「ローカル受付」）。
待ち受けポートは人の判断が要る項目で、2026-10-18 に 41630 と決めた（stockroom は 41620・41621・41640 を使う）。

## 決定

desktop-platform の Optional Standard「ローカル受付」に従い、`src-tauri/src/extension.rs` が **127.0.0.1:41630** で待ち受ける。

- **既定はオフ**。設定でオンにしている間、アプリが動いているときだけ待ち受ける
- `Host` が `127.0.0.1:41630` / `localhost:41630` 以外は拒否。`Origin` が付いていてブラウザ拡張のものでなければ拒否（Web ページから使わせない）
- すべての要求に `Authorization: Bearer <token>`。token はアプリが作り、`settings.json` の `extension.token` にだけ置く（窓には渡さない）。アプリが書き出した拡張のコピーは `config.json` で、ほかのコピーは `POST /pair`（4 桁の番号を両方に出して許可）で受け取る。拒否された拡張は 30 秒待つ。質問は同時に 1 つ
- 受け付けるのは 2 つだけ：
  - `POST /subscribe?url=`：フィードかページの URL を購読する（「フィードを追加」と同じ処理。フィードを取りに行くのは ADR-0001 の範囲のまま）
  - `POST /later?url=&title=`、本文はページの HTML（5 MB まで）：「あとで読む」に入れる。**アプリはページを取りに行かない**。拡張がブラウザで開いているページの HTML を送り、アプリは `fulltext::extract` で本文を抜き出す
- 待ち受けは `loopback.rs`（stockroom から写したもの）に寄せ、tiny_http の上に書く（Recommendations の既定）。アプリへの依存は trait（`Host`）で挟み、Tauri なしでテストする
- フェーズ 8 の MCP は **41631** を予定にする（用途が違うので、サーバーも token も分ける）

## 理由

- **拡張がページの URL だけを送り、アプリがページを取りに行く案**：ADR-0001 の範囲が広がり、ログインが要るページはアプリからは取れない。拡張はブラウザの Cookie で表示済みの HTML を持っている（Standard §4「アプリは URL を取りに行かない」）
- **拡張から直接フィードを購読させる（アプリは URL を受けるだけ）案**：今の「フィードを追加」の処理（ページからのフィードの探索、重複の検査）を拡張に書き直すことになる
- **stockroom の受付（41620）に相乗りする案**：別のアプリの受付で、token も許可も別。片方を止めるともう片方が止まる
- **`articles.feed_id` を NULL にできるようにする案**：SQLite では列の制約を変えるのに表を作り直す必要があり、記事を読む問い合わせはどれも `feeds` と JOIN している。「保存したページ」のフィードの行を 1 つ作り、サイドバー・更新・OPML から外すほうが変更が小さい

## 影響

- project-context の「外との接続」と「該当しない Standard」を直す（Optional「ローカル受付」が該当するようになる）
- README に待ち受けるポートを書く
- スキーマ v6：`feeds.saved`（「保存したページ」の行）
- アプリに拡張のファイルを同梱する（`bundle > resources`）。設定の「拡張機能のフォルダを用意して表示」で、`config.json` 入りのコピーを `app_data_dir()/extension` に書き出す

## 見直す条件

- 拡張から受け付けるものを足すとき（記事の一覧を読む、既読にするなど）。読み書きの範囲が広がるなら MCP（41631）と合わせて考え直す
- Chrome ウェブストアで配る（ペアリングだけにするか、ID を固定するか）
