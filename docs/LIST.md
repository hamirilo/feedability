# 一覧の操作（並び順・次の未読・ここより上 / 下）

困っていること：記事を上から順に読む以外の手段が少ない。古い記事から読みたい、未読のあるフィードへ素早く移りたい、読む気のない記事をまとめて既読にしたい。

## 決定

- **並び順**：新しい順（既定）/ 古い順。表示の好み（`localStorage` の `feedability.prefs` の `oldestFirst`）なので、起動をまたいで残る。メニュー 表示 › 古い順に並べる、または一覧の上の矢印のボタン。変えたら一覧を先頭に戻す
  - **あとで読む**は入れた順のまま（[LATER.md](LATER.md)）。そこでは矢印のボタンとメニューを無効表示にする（場所は変えない）
- **N（次の未読の記事）**：選んでいる記事より下の最初の未読の行を開く（何も選んでいなければ先頭から）。記事を開くと既読になるが行は一覧に残るので、「選んでいる行より下」で足りる
  - 一覧に無ければ、フィードかフォルダを開いている間は、未読のある次のフィードを開いてその最初の未読の記事を選ぶ。無ければ「未読の記事はもうありません」
- **Shift+J / Shift+K（次 / 前のフィード）**：サイドバーに出ている順（フォルダごとにそのフィード、そのあとフォルダに入っていないフィード）で動く。端は反対側へ回る。未読のみが入っているときは未読 0 のフィードを飛ばす。フィード以外を開いているときは、次は先頭、前は末尾。記事は選ばない
  - フォルダの開閉は無視する。閉じたフォルダの中のフィードへ移ったら、そのフォルダを開く
  - 「次の未読のあるフィード」の起点は、開いているフィード。フォルダを開いているときはそのフォルダの最後のフィード
- **ここより上 / 下を既読にする**：選んでいる記事（含まない）より上 / 下の未読を既読にする。記事の右クリックとメニュー 記事から。キーは付けない。取り消せるトーストは「一覧をすべて既読にする」と同じ（元に戻す）
  - 右クリックはまずその行を選ぶ（開くので既読になる）。メニューはその記事に対して働く
- **すべて既読にしたら次のフィードへ移る**（設定、既定はオフ）：一覧のすべて既読のあと、フィードかフォルダを開いていれば、未読のある次のフィードを開く（記事は選ばない）。元に戻すのトーストは出る

## 実装

- Rust：`ArticleQuery.oldest_first`（`db::query_articles` の `ORDER BY`。`View::Later` は無視）。設定は `AppSettings.next_feed_after_read_all`
- フロント：`store.ts` の `oldestFirst`、`feedOrder` / `openFeed` / `nextUnreadFeed` / `nextUnread` / `moveFeed`、`markAbove` / `markBelow`（既読にして取り消せるトーストを出す部分は `announceRead`）。`reload` と `setView` は共通の `load` / `switchView` を通り、一覧が入るのを待てる（古い問い合わせの答えは捨てる）
- コマンド表：`go.nextUnread`（N）、`go.nextFeed`（Shift+J）、`go.prevFeed`（Shift+K）、`list.oldestFirst`、`list.markAboveRead`、`list.markBelowRead`
