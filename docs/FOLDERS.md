# フォルダへの移動（ドラッグ）

困っていること：フィードをフォルダに入れるには、右クリック › フォルダへ移動… でダイアログを開き、一覧から選ぶしかない。何件も整理するときに手間がかかる。

## 決定

- **サイドバーのフィードを、フォルダへドラッグして移す**（stockroom のフォルダと同じ操作感）
  - フォルダの行、またはそのフォルダの中のフィードの上で離すと、そのフォルダへ移る。移す先のフォルダの行が青く浮き上がる
  - フォルダの外へ出すときは、フォルダに入っていないフィードの並び（とその下の空き）の上で離す。フォルダの中のフィードをドラッグしている間だけ、その並びの先頭に「ここにドロップでフォルダの外へ」の枠を出す
  - ポインタの横に、フィードの名前と行き先（「〇〇」へ / 移動先のフォルダへドロップ）を出す
  - 閉じたフォルダの上で少し待つと開く。閉じたフォルダへ落としたときも開き、移したフィードが見える
  - 今いるフォルダの上で離しても何もしない。Esc でやめる
  - 5 px 動かすまではクリック（フィードを開く）のまま
- 右クリックとメニューの「フォルダへ移動…」は残す（キーボードだけでも移せるように）
- フォルダの並べ替え・入れ子は今回はしない（フォルダは名前順のまま）

## 実装

- `Sidebar.tsx`：ポインタのイベントで作る（HTML5 のドラッグ & ドロップは、Tauri のファイルのドロップを受けると Windows で効かなくなるため。stockroom の `DragLayer.tsx` と同じ理由）。行き先は `data-drop`（`folder:<id>` / `root`）を `elementFromPoint` で拾う。移すのは今までと同じ `actions.ts` の `moveFeed`（Rust の `move_feed`）なので、API とモックは変わらない
- ドラッグ中は `<html data-dragging>` を付け、`index.css` でカーソルを握った手にする
