# ペインの幅（サイドバー・記事の一覧）

困っていること：サイドバーのフィード名や一覧のタイトルが長いと切れる。広い画面では本文を広く、狭い画面では一覧を細くしたいが、幅が固定で変えられない。

## 決定

- **サイドバーと記事の一覧は、右の端をドラッグして幅を変えられる**。既定はサイドバー 240px、一覧 380px。ダブルクリックで既定に戻る
- **限りは**サイドバー 180〜400px、一覧 280〜640px。どちらも **本文は 360px 以上** 残す（残りが足りなければ、ドラッグしている側がそこで止まる）
- ウィンドウを狭めたときは、描く幅だけを縮める（サイドバー、一覧の順に）。保存した値は書き換えないので、ウィンドウを広げれば元の幅に戻る
- **キーボード**：つまみ（`role="separator"`）にフォーカスして ←/→ で 16px ずつ。Tab で移れる
- 幅は表示の好み（`localStorage` の `feedability.prefs` の `sidebarWidth` / `listWidth`）。**ドラッグを離したときに保存**し、動かしている間は保存しない
- 操作のボタンの位置は変えない。幅が変わるだけで、各ペインの上の操作は同じ並びのまま

## 実装

- `src/lib/layout.ts`：既定・下限・上限・本文の最小幅と、窓の幅から描く幅を決める `paneWidths`（ストアに依存しない関数）
- `src/components/ResizeHandle.tsx`：つまみ。ポインターイベント + `setPointerCapture`（HTML5 の DnD は使わない）。端の 5px（枠線に重ねる）が当たり判定で、ホバー・ドラッグ・フォーカスで細いアクセント色の線を出す。`usePaneWidths` が保存値と窓の幅から描く幅を返す
- `store.ts`：`sidebarWidth` / `listWidth`、`setPaneWidth`（メモリのみ）/ `savePaneWidths` / `resetPaneWidth`
