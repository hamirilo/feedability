# フィードのアイコン

困っていること：サイドバーも一覧もフィードが文字だけで、似た名前のフィードを見分けにくい。

## 決定

- **サイドバーのフィードの行（14px）、一覧の行のフィード名の前（12px）、本文の見出しのフィード名の前（12px）** にアイコンを出す。まだ無い・取れなかったフィードは、これまでの汎用のアイコン（同じ大きさ）
- **探す順**（最初に画像が得られたものを使う）。ADR-0001 に決定として書いてある
  1. フィード自身のアイコン（Atom の `<icon>`）
  2. サイトのページの `<link rel="icon">` / `shortcut icon` / `apple-touch-icon`。`icon` のうち `sizes` が無い・16x16・32x32 のものを先に、次にそれ以外の `icon`、最後に apple-touch-icon
  3. サイトの `/favicon.ico`
  4. フィードのロゴ（RSS の `<image>`、Atom の `<logo>`）
- **サイト**はフィードの `site_url`。無ければフィードの URL のオリジン
- 1 つのフィードにつき **30 日に 1 回まで**。見つからなかったときも確認した時刻を残し、更新のたびに探し直さない。見つからなかった／サイトが答えなかったときは、すでにあるアイコンを消さない
- **上限 256 KB**。中身で形式を判定し（`fetch::image_type`）、画像でないもの・SVG は使わない。ページから探すのは先頭の 3 つまで（ページの読み込みは 2 MB まで）
- 通信は Rust（`fetch.rs`）だけ。WebView は外へ出ず、アイコンは `data:` URL で渡す
- **いつ探すか**：更新（`refresh_feeds`）が終わったあと、購読したあと、URL を付け替えたあと。更新や購読の応答は待たせず、裏で 6 本ずつ。終わったら `icons-changed` を出す。アイコンの失敗は更新・購読・付け替えの失敗にしない（ログのみ）
- URL を付け替えたフィードは、古いアイコンを消して探し直す（[FEED_INFO.md](FEED_INFO.md)）
- 探している間に URL が付け替えられたら、その結果は捨てる（古いサイトのアイコンなので）。`set_icon` は探したときの URL のフィードにだけ書き、確認の時刻も付けないので、新しいサイトの分は次の探索で探す

## 実装

- **フィード自身のアイコンとロゴの URL は、パースのたびに `feeds.icon_url` / `logo_url` に残す**。アイコンの探索は更新と別に（フィードを取り直さずに）走るので、パースした結果のうちここで要るものを列に持たせた。更新で毎回上書きするので、フィード側で変わっても 30 日以内に追いつく
- DB（スキーマ v3）：`feeds.icon`（`data:` URL）、`icon_checked_at`、`icon_url`、`logo_url`。`feeds_needing_icon` / `set_icon` / `set_icon_urls` / `icons`
- Rust：`feed.rs` の `ParsedFeed.icon` / `logo`、`icon_links`。`commands.rs` の `fetch_icon` と、裏で走らせる `icon_pass`（同時に 1 つ。走っている間に頼まれたら、終わってからもう一度）。コマンド `feed_icons`
- フロント：ストアの `icons`（**サイドバーのペイロードには入れない**。サイドバーは読むたびに取り直すので重くなる）。`init` と `icons-changed` で読む。`FeedIcon.tsx`
