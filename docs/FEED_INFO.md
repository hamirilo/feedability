# フィードの情報と URL の変更

困っていること：サイドバーの赤い印は「更新できなかった」としか言わず、理由はマウスを載せたときの一行だけ。移転したサイトの URL を直すには、購読をやめて入れ直すしかなく、記事の既読も消える。

## 決定

- **フィードの情報**（⌘I、フィード › フィードの情報…、サイドバーのフィードの右クリックの先頭、赤い印のクリック）：開いているフィードについて次を出す
  - 名前（付け替えていれば「元の名前」も）、URL、サイト（クリックでブラウザへ）、フォルダ、追加した日、最後に更新した日時、記事の数（未読の数）
  - 更新できなかったときは「更新できませんでした」の枠に理由の全文
  - 赤い印のクリックは、右クリックと同じくそのフィードを開いてから情報を出す（行を選ぶだけで終わらない）
- **URL の変更**：欄を直して「変更」。フィードの URL でも、フィードを載せたページの URL でもよい（購読するときと同じに探す）
  - 新しい URL は、フィードとして読めることを確かめてから付け替える。確認の間は「確認しています…」。失敗は欄の下に出し（トーストだけにしない）、何も変わらない
  - ほかのフィードがすでにその URL なら「このフィードはすでに購読しています」。ページから探した先が購読済みの場合も同じ
  - 付け替えで **残る**：記事（既読・スター・あとで読む）、付けた名前、フォルダ。記事は guid で見分けるので、同じフィードなら重ならない。**消える**：ETag / Last-Modified、エラー、サイトの URL（新しいフィードが名乗るものに替わる。名乗らなければ無し）、アイコン（新しいサイトで探し直す。[FAVICON.md](FAVICON.md)）
  - 取れた内容でフィード自身の名前とサイトの URL も更新し、最後に更新した日時を今にする
  - 成功したら、サイドバーと一覧を取り直し「URL を変更しました」。ダイアログは開いたまま、表示が新しくなる

## 実装

- Rust：`get_feed_info(id)` → `FeedInfo`、`change_feed_url(id, url)` → `FeedInfo`（`commands.rs`）。ページ → フィードの探索は追加と共通の `fetch_feed_or_page`。DB の付け替えは `db::change_feed_url`（URL の UNIQUE 違反はエラー）、続けて `feed_fetched` と `store_articles`
- フロント：`Dialog` の `feedInfo`、`FeedInfoDialog.tsx`、`actions.ts` の `changeFeedUrl`、コマンド `feed.info`
