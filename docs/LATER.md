# あとで読む

困っていること：スターは「取っておく」ためのもので、読むつもりで付けた記事と保存したい記事が混ざる。読み終えたものを外すのも手間。

## 決定

- **あとで読む** はスターと別の、読み終えたら消えていく「積んだ記事の山」。スターは今までどおり、自分で外すまで残る保存
- 入れる・外す：記事を開いて **L**、本文の上の時計のボタン、メニューの 記事 › あとで読む
- サイドバーの「すべての記事」の下に **あとで読む**（⌘2）。件数を出す。スター付きは ⌘3 に移した
- 並びは **入れた順（古いものが上）**。上から順に片付けていく
- **読み終えたら自動で外れる**：あとで読むに入っていた記事を開き、別の記事か別の表示へ移ったら外れる。読んでいる途中で L を押したとき（入れた・外した）は、その操作を優先して自動では外さない
  - 外れた記事の行は、一覧を問い合わせ直すまで残る（時計の印だけ消える）。戻したければ開いて L
- **未読のみは効かない**：スター付きとあとで読むでは、読んだ記事も出す（一度読んでから「あとでちゃんと読む」と入れることが多いため）。一覧の上の「未読 / すべて」はその間だけ無効表示にし、場所は変えない
- 古い記事の整理（設定「既読の記事を残す期間」）で、あとで読むに入っている記事は消さない

## 実装

- `articles.later_at`（入れた時刻。入っていなければ NULL）。スキーマ v2（`PRAGMA user_version = 2`）で列を足した。v1 のファイルは開いたときに足す。古い版のアプリで開いても、この列を無視するだけで壊れない
- Rust：`db::set_later`（入れる・外す。すでに入っている記事は場所を保つ）、`View::Later`（`later_at` の順）、`View::filters_unread`、`purge` の条件
- フロント：`store.ts` の `finishOnLeave` と `leave`（読み終えたら外す）、`toggleLater`。コマンド表の `article.later`（L）と `view.later`（⌘2）
